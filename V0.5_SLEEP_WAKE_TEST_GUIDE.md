# Pocket Watch v0.5.0: AMOLED Sleep, Touch Recovery, and Serial Echo

This overlay updates the existing v0.4.0 pocket-watch project. Existing Wi-Fi
credentials, battery telemetry, flicker-free clock rendering, and 12/24-hour
touch switching are preserved.

## Installation

1. Close PlatformIO Serial Monitor so COM18 is available.
2. Extract this ZIP into the existing pocket-watch project directory.
3. Allow Windows to replace `src/main.cpp`.
4. Build and upload, then reopen Serial Monitor at 115200 baud.

PowerShell alternative:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run -e pocket_watch -t upload
```

## Behavior

- While connected to USB, the display remains on.
- On battery, the AMOLED automatically sleeps after 30 seconds of inactivity.
- The first tap wakes the display without switching between 12- and 24-hour
  time. The next deliberate tap switches time format normally.
- Touchscreen identification is retried during startup. If touch is not ready,
  both automatic and manual screen sleep are blocked to avoid trapping the
  display in a state it cannot wake from.
- Reconnecting USB wakes a sleeping display within approximately five seconds.
- Battery monitoring and timekeeping continue while the display is asleep.
- Typed serial commands are echoed immediately, including backspace edits.

This checkpoint sleeps the display controller; it does not put the ESP32-S3
processor into light sleep or deep sleep. CPU-level sleep and power-button
wake can be tested separately after display sleep is proven reliable.

## Serial commands

```text
sleep            Turn the AMOLED off immediately.
wake             Turn the AMOLED back on.
touch            Report whether the CST9217 touchscreen is ready.
touch probe      Retry touchscreen initialization and restore the AMOLED.
timeout          Report the current battery-only sleep timeout.
timeout 10       Set the battery-only sleep timeout to ten seconds.
timeout 30       Restore the default thirty-second timeout.
timeout off      Disable automatic battery-only display sleep.
brightness 64    Lower display brightness; valid values are 1-255.
brightness 128   Restore the default display brightness.
battery          Show AXP2101 battery and charging telemetry.
status           Show the clock, display, timeout, and battery state.
```

Timeout and brightness changes currently last until the next restart.

## Suggested hardware checks

1. With USB connected, type `status` and confirm `Touch: CST9217 READY`.
2. Tap the awake screen and verify that 12/24-hour mode changes once.
3. If touch is not ready, type `touch probe`, then repeat `status`.
4. Type `sleep`; the display should turn off while Serial Monitor stays alive.
5. Tap the screen once; it should wake without changing the time format.
6. Tap again; it should switch between 12-hour and 24-hour display.
7. Type `timeout 10`, unplug USB, and wait ten seconds for automatic sleep.
8. Tap to wake, then verify that the current time is still correct.
9. Allow it to sleep again, reconnect USB, and verify automatic waking.
10. Restore `timeout 30` if desired.
