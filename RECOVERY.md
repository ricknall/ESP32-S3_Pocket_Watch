# Factory recovery

Before experimenting further, keep the official factory recovery package
available. Waveshare publishes recovery firmware and flash instructions here:

- https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75C
- https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-1.75C/Resources-And-Documents

The vendor repository's `Firmware` directory contains the factory images. Its
README describes the combined-image Windows flashing procedure.
