# Pocket Watch Clock v0.3.0 test checklist

## Before upload

- Copy `include/WatchConfig.example.h` to `include/WatchConfig.h`.
- Enter the 2.4 GHz Wi-Fi name and password in the new file.
- Stop Serial Monitor before uploading.

## First boot

Confirm the screen progresses through:

1. `WAITING FOR NTP`
2. `CONNECTING WI-FI`
3. `SETTING GOD'S TIME`
4. a valid Central Time clock face
5. `NTP SYNCED CDT` or `NTP SYNCED CST`

In Serial Monitor, retain the startup lines through `Local time:`.

## Touch test

Tap once near the center. The face should change from 12-hour to 24-hour time
exactly once. Tap again after one second; it should return to 12-hour time
exactly once.

Success means:

- no repeated display toggling from one tap;
- no repeating I2C NACK or `ESP_ERR_INVALID_STATE` messages;
- normal empty touch IRQ packets produce no message.

## Retry commands

- `status` prints the clock and hardware state.
- `sync` retries Wi-Fi and NTP.
- `12` and `24` select a display mode without touching the screen.

Send back a screen photo plus the startup/status output. Do not include the
contents of `WatchConfig.h`.
