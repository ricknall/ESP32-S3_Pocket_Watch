# Pocket Watch v0.4.0: AXP2101 Battery Telemetry

This overlay updates only `src/main.cpp`. It is intended for the existing
`ESP32-S3_Pocket_Watch` project at release `v0.3.1`; existing Wi-Fi
credentials and the working display/touch configuration are preserved.

## Installation

1. Close PlatformIO Serial Monitor so COM18 is not held open.
2. Extract the ZIP into the existing pocket-watch project directory.
3. Allow Windows to replace `src/main.cpp`.
4. Build and upload using the PlatformIO checkmark and right-arrow.
5. Reopen Serial Monitor at 115200 baud.

PowerShell alternative, run from the pocket-watch project directory:

```powershell
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run -e pocket_watch -t upload
```

## New serial commands

- `battery` prints battery presence, voltage, state of charge, USB input,
  charging state, USB voltage, system voltage, and raw PMU status registers.
- `power` is an alias for `battery`.
- `status` includes the normal clock report followed by the battery report.

## Hardware checks

With USB connected, type `battery` and verify:

- AXP2101 is detected at I2C address `0x34`.
- The battery is reported as connected.
- Battery voltage is plausible for a single lithium cell, typically about
  3000-4200 mV depending on charge.
- USB power is reported as present.
- Charging is reported if the battery is actively accepting charge; a full
  battery can legitimately show charging stopped or complete.

The watch face should show a line similar to `BAT 82%  3.97V  CHG`.
Disconnect USB and verify the watch remains running and the label changes to
`BAT` within approximately five seconds. Reconnect USB and verify that it
returns to `CHG` or `USB`.

The PMU's fuel-gauge percentage can require settling and should be treated as
an estimate until compared with observed runtime. If no valid percentage is
available, the watch still displays the measured battery voltage.

## Safety boundary

This firmware only enables AXP2101 battery detection and ADC measurement
channels. It does not alter charge current, charging voltage, temperature
limits, or power-rail configuration.
